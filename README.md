# Godot-Level2-Workshop

This is a Godot game project used in Level 2 workshops by [NUS GDG](https://nusgdg.org/).

Video recordings of the workshops can be found [here](https://www.youtube.com/@nusgamesdevelopmentgroup9090).


## Usage (important)
The main branch contains the initial project.

Each branch with name `week{n}-{topic}-{'before'|'after'}` stores relevant workshop content for that week, **before or after** the workshop. The difference between **before** and **after** branches will be covered in the workshop.

Thus, download the **before** branch before coming to workshops. If needed, you can refer to the **after** branch as a reference.
